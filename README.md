# Play With Snake · 贪吃蛇大冒险

PyQt6 + HTML/JS 实现的局域网联机贪吃蛇：桌面客户端与服务器均为 PyQt6 程序，界面沿用同一套白色浅色设计语言；支持单人、双人、2–4 人联机对战、自制地图、回放与排行榜。

- 客户端：PyQt6 外壳 + 内置 HTML 页面（本机回环 HTTP 托管）
- 服务端：PyQt6 控制台 + 权威对局服务器（HTTP 8080 / WebSocket 8081）
- 局域网玩家可直接用浏览器打开 `http://<服务器IP>:8080/` 加入，无需安装

## 功能特性

### 游戏
- 单人挑战 / 双人对战 / 2–4 人联机对战（服务器权威判定）
- 9 种食物与道具：苹果、金星、宝石、闪电（加速）、乌龟（减速）、幽灵（穿墙）、剪刀（缩短）、护盾（可叠加）、传送门
- 5 档难度、经典随机地图与自制地图、连击倍数、蛇皮肤
- 每局自动保存完整回放，支持倍速与拖动进度

### 客户端
- 灵动岛：实时显示服务器连接状态与地址
- 系统托盘：启动隐藏到托盘、关闭最小化到托盘、托盘右键菜单
- 联机入口位于「对战模式」；联机排行榜独立分类（联机单人 / 联机双人）
- 成绩校验：被篡改记录显示「分数异常」并红色高亮，**自动隐藏上传按钮**；支持「一键上传」
- 自制地图上传到服务器并在联机建房时选用（导入/导出/预览/编辑）
- 操作日志通过 QtSql(SQLite) 持久化并可导出
- 设置按功能分组：地图 / 外观 / 操作 / 联机 / 数据与统计

### 服务端
- Qt 卡片式控制台：运行状态、基本设置、防火墙与自启动、局域网地址、房间与连接、联机用户与 IP 备注、实时日志
- 访问密码（scrypt 哈希 + 会话 Cookie + 失败递增锁定），HTML 面板仅保留密码与排行榜
- 开机/登录自启动（schtasks），非管理员自动降级；一键放行防火墙端口
- 托盘常驻，`--tray` 启动即隐藏
- 联机排行榜仅保留前 30 名，自动过滤签名不符的异常数据

## 架构与端口

```
┌──────────── 客户端（PyQt6） ────────────┐
│ QWebEngineView ← 本机回环 HTTP 托管页面 │
│ QWebChannel 桥（网络/地图/日志/系统）   │
│ QWebSocket ─────────────┐               │
│ QtSql SQLite（日志/地图）│               │
└─────────────────────────┼───────────────┘
                          │ ws://IP:8081
┌──────────── 服务端（PyQt6） ────────────┐
│ HTTP 8080：页面 + REST + 面板            │
│ WS 8081：QWebSocketServer 权威对局       │
│ UDP 41999：内网自动发现                  │
│ 游戏引擎 / 房间 / 排行榜 / 访问密码      │
└──────────────────────────────────────────┘
```

| 端口 | 协议 | 用途 |
|---|---|---|
| 8080 | HTTP | 页面分发、REST（排行榜/地图/发现）、访问密码与排行榜面板 |
| 8081 | WebSocket | 联机对局协议 |
| 41999 | UDP | 内网自动发现广播 |

协议字段、快照结构、签名算法详见 [text/PROTOCOL.md](text/PROTOCOL.md)。

## 快速开始（源码运行）

```bat
git clone https://github.com/moshushiwwq/play-with-snake.git
cd play-with-snake
python -m pip install -r requirements.txt
```

启动服务端：

```bat
python server/main.py --port 8080 --ws-port 8081
```

启动客户端：

```bat
python client/main.py
```

- 客户端启动后自动加载内置页面
- 顶部灵动岛填入服务器 IP 连接（默认端口 8080 / 8081）
- 局域网其他玩家浏览器打开 `http://<服务器IP>:8080/` 即可加入

## 打包 exe

```bat
python build\release.py
```

产物：

```
release/
├─ PlayWithSnake-Client/     # 客户端 onedir
├─ PlayWithSnake-Server/     # 服务端 onedir
└─ version.json              # 版本与校验信息
```

也可单独构建：`python build\release.py --client` 或 `--server`。

## 跨网络联机

1. 服务端监听 `0.0.0.0`，同一局域网可直接连接；
2. 跨公网需在路由器把 **TCP 8080、TCP 8081、UDP 41999** 映射到服务器主机；
3. 以管理员运行时可在服务端界面一键放行 Windows 防火墙。

## 常见问题

- **连接失败**：确认服务端已启动、端口正确、防火墙放行 8080/8081。
- **页面空白 / 无法联网**：请通过客户端或 `http://服务器IP:8080/` 访问，不要直接双击本地 html（`file://` 会受限）。
- **开机自启无效**：需要管理员权限；普通用户会自动降级为登录自启或启动文件夹快捷方式。
- **排行榜为空**：需先连接服务器并提交成绩；服务端会拒绝签名不符的记录。

## 已知限制

- 签名密钥内嵌在客户端：篡改数据后重算签名仍可提交；服务端能拦下未重签的篡改，客户端侧的「提交」按钮依赖本地校验。
- 跨公网联机依赖端口映射，未内置中继服务器。
