# Play With Snake · 贪吃蛇大冒险

PyQt6 + HTML/JS 实现的局域网联机贪吃蛇：两端都不再内嵌 Qt WebEngine，游戏界面全部在系统默认浏览器中打开；PyQt6 客户端只负责发现局域网服务器并把服务器页面交给浏览器。支持单人、双人、2–4 人联机对战、自制地图、回放与排行榜。

- 客户端：PyQt6 启动器（搜索局域网服务器 → 直接用浏览器打开服务器页面，普通用户权限运行）
- 服务端：后台驻留 + 托盘常驻（不弹主窗口），权威对局服务器（HTTP 8080 / WebSocket 8081）
- 局域网玩家可直接用浏览器打开 `http://<服务器IP>:8080/` 加入，无需安装
- 管理面板通过客户端「管理员选项」在浏览器中打开，需用户名 + 密码登录

## 功能特性

### 游戏
- 单人挑战 / 双人对战 / 2–4 人联机对战（服务器权威判定）
- 9 种食物与道具：苹果、金星、宝石、闪电（加速）、乌龟（减速）、幽灵（穿墙）、剪刀（缩短）、护盾（可叠加）、传送门
- 5 档难度、经典随机地图与自制地图、连击倍数、蛇皮肤
- 每局自动保存完整回放，支持倍速与拖动进度

### 客户端
- 启动后自动在局域网内搜索服务器（UDP 41999 广播），找到唯一或上次用过的服务器就直接用系统默认浏览器打开它的页面
- 多台服务器时在列表里选择；也可手动填写 `IP` 或 `IP:端口` 直接打开
- 单实例：重复双击只会把已有窗口带到前台并重新搜索
- 全程普通用户权限：不请求管理员、不改注册表与防火墙、不写系统目录；界面文案不使用表情符号
- 局域网玩家也可不用客户端，浏览器直接打开 `http://<服务器IP>:8080/`

### 游戏页面（浏览器内）
- 灵动岛：实时显示服务器连接状态与地址；连接面板提供「管理员选项」，点击即在浏览器打开服务端面板
- 联机入口位于「对战模式」；联机排行榜独立分类（联机单人 / 联机双人）
- 成绩校验：被篡改记录显示「分数异常」并红色高亮，**自动隐藏上传按钮**；支持「一键上传」
- 自制地图上传到服务器并在联机建房时选用（导入/导出/预览/编辑）
- 设置按功能分组：地图 / 外观 / 操作 / 联机 / 数据与统计

### 服务端
- 后台驻留：启动后不显示主窗口，托盘常驻；右键托盘菜单可查看运行日志、当前 IP/端口与总运行时长，并打开管理面板、启动/停止服务、退出
- 管理员账号：用户名 + 密码（scrypt 哈希 + 会话 Cookie + 失败递增锁定），用户名与密码均可在面板修改，默认用户名 `admin`
- HTML 管理面板：账号修改、开机自启动、内网发现开关、两端启动动画开关、排行榜
- 开机/登录自启动（schtasks），非管理员自动降级；每次启动服务成功后自动放行 TCP 8080/8081 与 UDP 41999 防火墙规则
- 联机排行榜仅保留前 30 名，自动过滤签名不符的异常数据

## 架构与端口

```
┌──────────── 客户端（PyQt6 启动器） ────────┐
│ UDP 41999 广播探测 + HTTP /api/discover     │
│ 服务器列表 / 手动地址 / 上次服务器记忆       │
│ QDesktopServices 拉起系统浏览器 ──┐          │
└───────────────────────────────────┼─────────┘
                                     │ 浏览器直开服务器页面
┌───────────────────────────────────┼─────────┐
│ 浏览器：http://IP:8080/index.html（WS + fetch）│
└───────────────────────────────────┼─────────┘
                          ws://IP:8081 · http://IP:8080
┌──────────── 服务端（PyQt6 后台） ──────┐
│ HTTP 8080：页面 + REST + 管理面板      │
│ WS 8081：QWebSocketServer 权威对局     │
│ UDP 41999：内网自动发现                  │
│ 游戏引擎 / 房间 / 排行榜 / 账号鉴权      │
└──────────────────────────────────────────┘
```

| 端口 | 协议 | 用途 |
|---|---|---|
| 8080 | HTTP | 页面分发、REST（排行榜/地图/发现）、账号鉴权与管理面板 |
| 8081 | WebSocket | 联机对局协议 |
| 41999 | UDP | 内网自动发现广播 |

协议字段、快照结构、签名算法详见 [text/PROTOCOL.md](text/PROTOCOL.md)。

## 快速开始（源码运行）

```bat
git clone https://github.com/moshushiwwq/play-with-snake.git
cd play-with-snake
python -m pip install -r requirements.txt
```

启动服务端：

```bat
python server/main.py --port 8080 --ws-port 8081
```

启动客户端：

```bat
python client/main.py
```

- 客户端启动后自动搜索局域网服务器，找到唯一（或上次用过的）服务器即用系统默认浏览器打开其页面
- 多台服务器时在窗口列表里选择，或直接填写 `IP` / `IP:端口` 打开；`python client/main.py --no-auto` 只搜索不自动打开，`--url <地址>` 只打开指定地址
- 普通用户权限即可运行，不需要管理员确认

## 打包 exe

打包必须在 **Windows** 上执行（PyInstaller 不支持交叉编译，Linux 上无法生成 `.exe`）。前置依赖：

```bat
python -m pip install -r requirements.txt
python -m pip install pyinstaller
```

一键构建双端：

```bat
python build\release.py
```

产物：

```
release/
├─ PlayWithSnake-Client.exe  # 客户端单文件 exe
├─ PlayWithSnake-Server.exe  # 服务端单文件 exe
└─ version.json              # 版本与校验信息

build/logs/build-*.log       # 完整构建日志（保留，便于排查）
```

两个 exe 均为 PyInstaller 单文件模式，内置 Python 与 PyQt6 运行时，目标机器无需安装 Python 或任何第三方依赖；双击即可运行。静态页面（`client/web`、`server/web`）已打入 exe，启动时解压到临时目录并由 `server/paths.py` 的 `resource_path()` 解析，不依赖源码目录。

运行数据位置：服务端在 exe 同目录生成 `server_data/`（配置、排行榜、地图、日志）；客户端在 `%LOCALAPPDATA%\PlayWithSnake\` 保存 `client.ini`（上次服务器地址、窗口位置）。

也可单独构建：`python build\release.py --client` 或 `--server`；或直接运行 `build\build_client.bat` / `build\build_server.bat`。打包脚本会先同步 `version.js` 并生成图标 `build\assets\app.ico`，并把完整过程写入 `build/logs/build-*.log`。

## 跨网络联机

1. 服务端监听 `0.0.0.0`，同一局域网可直接连接；
2. 跨公网需在路由器把 **TCP 8080、TCP 8081、UDP 41999** 映射到服务器主机；
3. 以管理员运行时可在服务端界面一键放行 Windows 防火墙。

## 常见问题

- **搜得到但连不上**：多为 Windows 防火墙拦截了 TCP 8080/8081。服务端启动成功后会自动尝试放行；若以普通用户运行导致放行失败，请右键「以管理员身份运行」服务端，或手动在防火墙入站规则放行 TCP 8080/8081 与 UDP 41999。
- **页面空白 / 无法联网**：请通过客户端拉起的浏览器页面或 `http://服务器IP:8080/` 访问，不要直接双击本地 html（`file://` 会受限）。
- **开机自启无效**：需要管理员权限；普通用户会自动降级为登录自启或启动文件夹快捷方式。
- **排行榜为空**：需先连接服务器并提交成绩；服务端会拒绝签名不符的记录。

## 已知限制

- 签名密钥内嵌在客户端：篡改数据后重算签名仍可提交；服务端能拦下未重签的篡改，客户端侧的「提交」按钮依赖本地校验。
- 跨公网联机依赖端口映射，未内置中继服务器。
