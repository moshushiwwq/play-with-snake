# 使用说明（v3.1.0）

## 运行环境

- Windows 10/11（其他平台仅部分功能可用）
- Python 3.10+（源码运行）
- 依赖：`pip install -r requirements.txt`

## 从源码运行

服务端（局域网主机）：

```bat
python server/main.py --port 8080 --ws-port 8081
```

启动后：
- 浏览器玩家访问 `http://<本机局域网IP>:8080/`
- 桌面客户端连接 `<本机局域网IP>:8081`
- 托盘右键菜单可显示/隐藏窗口、启停服务、打开「访问密码与排行榜」、退出

客户端：

```bat
python client/main.py
```

- 启动后自动加载内置页面（由本机回环 HTTP 托管，避免本地文件联网限制）
- 关闭窗口默认最小化到托盘（可在设置中关闭）
- `python client/main.py --tray` 启动即隐藏到托盘

## 联机

1. 主界面顶部「灵动岛」点击「连接」，填入服务器 IP（端口默认 8080/8081，可写 `IP:8081`）。
2. 连接不需要昵称：会自动使用「玩家」输入框中的名字，未填写则生成一个默认名。
3. 对战模式选择「联机对战」，可创建房间或从公开房间列表直接加入。
4. 私密房间才需要输入 4 位房间码。
5. 房主点击「开始对战」后，所有玩家进入由服务端权威判定的对局。

## 跨网络联机

- 服务端监听 `0.0.0.0`，同一局域网内可直接连接。
- 跨公网需要路由器把 **TCP 8080、TCP 8081、UDP 41999** 映射到服务器主机。
- 管理员运行时可在服务端界面一键放行防火墙端口；普通用户会被提示需要管理员权限。

## 访问密码与排行榜

服务端主界面右上角「访问密码与排行榜」会打开一个内嵌网页面板：
- 访问密码：scrypt 高强度哈希，只保存盐与哈希；连续 5 次失败会锁定来源 IP（60 秒起翻倍，最长 15 分钟）。
- 排行榜：仅展示前 30 名，异常数据由服务端过滤，备注由管理员在桌面程序「联机用户与 IP」中维护。

## 自制地图

1. 主界面 →「地图编辑」，绘制墙体、设置尺寸与是否允许穿墙，保存并命名。
2. 设置 →「地图设置」→「自制地图」，可预览/编辑/上传/导出/删除。
3. 上传后服务器上的所有玩家都能在联机建房时选用该地图。

## 排行榜与成绩上传

- 排行榜仅展示前 30 名（本地榜与联机榜一致）。
- 被判定为篡改的记录会显示「分数异常」并红色高亮，且**不显示上传按钮**。
- 「一键上传」会批量提交正常成绩，自动跳过异常记录。

## 操作日志

桌面客户端把关键操作（连接、建房、开局、上传成绩/地图、清空数据等）写入本机 SQLite（QtSql），
可在设置 →「数据与统计」→「操作日志」中导出；浏览器模式下保存在本地存储。

## 打包 exe

```bat
python build\release.py           :: 双端构建 + 生成 version.json
python build\release.py --client  :: 只构建客户端
python build\release.py --server  :: 只构建服务端
```

产物输出到 `release/PlayWithSnake-Client`、`release/PlayWithSnake-Server`（onedir，可直接双击运行）。
图标由 `build/make_icon.py` 用 QPainter 自绘生成，不含任何表情或外部素材。

## 常见问题

- **连接失败**：确认服务端已启动、地址端口正确、防火墙已放行 8080/8081。
- **页面空白**：客户端会用本机回环 HTTP 托管页面；若手动用 `file://` 打开，联网与存储会受限，请改用客户端或服务器地址访问。
- **自启动无效**：开机自启需要管理员权限；普通用户会自动降级为「登录后自启」或启动文件夹快捷方式。
- **排行榜为空**：需要先在客户端连接服务器并提交成绩；服务器端会拒绝未通过签名校验的记录。
