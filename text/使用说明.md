# 使用说明（v3.1.0）

## 运行环境

- Windows 10/11（其他平台仅部分功能可用）
- Python 3.10+（源码运行）
- 依赖：`pip install -r requirements.txt`

## 从源码运行

服务端（局域网主机）：

```bat
python server/main.py --port 8080 --ws-port 8081
```

启动后：
- 服务端在后台驻留（不弹主窗口），托盘常驻；浏览器玩家访问 `http://<本机局域网IP>:8080/`
- 桌面客户端连接 `<本机局域网IP>:8081`
- 托盘右键菜单可打开管理面板、启停服务、退出

客户端：

```bat
python client/main.py
```

- 客户端启动后在局域网内搜索服务器：找到唯一（或上次用过的）那台，直接用系统默认浏览器打开它的游戏页面
- 多台服务器时在窗口列表里选择，也可在下方手动填写 `IP` 或 `IP:端口` 打开；`--no-auto` 只搜索不自动打开，`--url <地址>` 只打开指定地址
- 重复双击不会再开第二个窗口：会把已有窗口带到前台并重新搜索
- 全程普通用户权限运行，不需要管理员确认

## 联机

1. 主界面顶部「灵动岛」点击「连接」，填入服务器 IP（端口默认 8080/8081，可写 `IP:8081`）。
2. 连接不需要昵称：会自动使用「玩家」输入框中的名字，未填写则生成一个默认名。
3. 对战模式选择「联机对战」，可创建房间或从公开房间列表直接加入。
4. 私密房间才需要输入 4 位房间码。
5. 房主点击「开始对战」后，所有玩家进入由服务端权威判定的对局。

## 跨网络联机

- 服务端监听 `0.0.0.0`，同一局域网内可直接连接。
- 跨公网需要路由器把 **TCP 8080、TCP 8081、UDP 41999** 映射到服务器主机。
- 服务端每次启动成功后会自动尝试放行 TCP 8080/8081 与 UDP 41999；以管理员运行才能写入防火墙规则，普通用户会被跳过并在日志中提示。

## 管理员账号与排行榜

管理面板在外部浏览器中打开：客户端连接服务器后点连接面板的「管理员选项」，或服务端托盘菜单「打开管理面板」（`http://127.0.0.1:8080/panel`）。
- 账号：用户名 + 密码，scrypt 高强度哈希，只保存盐与哈希；用户名与密码均可在面板修改，默认用户名 `admin`；连续 5 次失败会锁定来源 IP（60 秒起翻倍，最长 15 分钟）。
- 面板可设置开机自启动、内网发现、两端启动动画开关，并查看排行榜。
- 排行榜仅展示前 30 名，异常数据由服务端过滤，备注由管理员在桌面程序「联机用户与 IP」中维护。

## 自制地图

1. 主界面 →「地图编辑」，绘制墙体、设置尺寸与是否允许穿墙，保存并命名。
2. 设置 →「地图设置」→「自制地图」，可预览/编辑/上传/导出/删除。
3. 上传后服务器上的所有玩家都能在联机建房时选用该地图。

## 排行榜与成绩上传

- 排行榜仅展示前 30 名（本地榜与联机榜一致）。
- 被判定为篡改的记录会显示「分数异常」并红色高亮，且**不显示上传按钮**。
- 「一键上传」会批量提交正常成绩，自动跳过异常记录。

## 操作日志

客户端是轻量启动器，不写日志文件：搜索与打开的结果直接显示在窗口顶部状态行；游戏内操作日志在
浏览器的本地存储中，可在设置 →「数据与统计」→「操作日志」中导出。

## 打包 exe

```bat
python build\release.py           :: 双端构建 + 生成 version.json
python build\release.py --client  :: 只构建客户端
python build\release.py --server  :: 只构建服务端
```

产物输出到 `release/PlayWithSnake-Client`、`release/PlayWithSnake-Server`（onedir，可直接双击运行）。
图标由 `build/make_icon.py` 用 QPainter 自绘生成，不含任何表情或外部素材。

## 常见问题

- **搜得到但连不上**：多为防火墙拦截 TCP 8080/8081；服务端启动会自动尝试放行，普通用户运行导致失败时请右键「以管理员身份运行」，或手动放行 TCP 8080/8081 与 UDP 41999。
- **页面空白**：请用客户端打开的页面（`http://服务器IP:8080/`）访问；若手动用 `file://` 打开本地 html，联网与存储会受限。
- **自启动无效**：开机自启需要管理员权限；普通用户会自动降级为「登录后自启」或启动文件夹快捷方式。
- **排行榜为空**：需要先在客户端连接服务器并提交成绩；服务器端会拒绝未通过签名校验的记录。
