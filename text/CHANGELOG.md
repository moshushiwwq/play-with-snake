# 更新日志

## v3.1.1（2026-11-01）— 自动发现与端口自适应

### 客户端
- 新增局域网服务器自动发现（`client/discovery.py`）：启动后先 UDP 广播（41999）探测，
  失败再回退探测本机 `127.0.0.1:8080`，找到服务器后自动连接，无需手动填写地址。
- 灵动岛联机弹层新增「搜索局域网服务器」按钮与服务器列表（名称 / 在线人数 / 地址），
  点击条目即可直接连接；服务器列表每 5 秒由服务端广播刷新。
- 地址输入框只填 IP 或 `IP:端口` 也能连上：客户端会询问服务器真实端口
  （`/api/discover`），依次尝试 `给定端口 / 给定端口-1 / 8080 / 8081`，
  探测失败时用自动发现结果兜底，彻底解决「服务端改了端口就连不上」。
- 内网 HTTP 请求统一使用直连 opener，绕开系统代理对内网地址的劫持。
- 页面改由固定端口（默认 17001，占用时向后顺延最多 40 个）托管，并把实际端口写入
  配置，使 `http://127.0.0.1:<端口>` 的 origin 跨启动保持不变，
  localStorage / IndexedDB（设置、存档、回放）不再每次启动就「丢失」。
- 单实例保护加入握手确认：只有旧实例回写 `OK` 才视为存活，否则清理残留管道并正常启动，
  修复异常退出后「双击程序没反应」的问题。

### 服务端
- 单实例保护同样加入握手确认，避免残留进程导致新实例静默退出。
- `--port / --ws-port` 命令行端口覆盖与内网发现信息保持一致。

### 已知限制
- 签名密钥内嵌在客户端：篡改数据后重新计算签名仍可提交；客户端侧的「提交」按钮
  依赖本地校验拦截，服务端只能拦下未重签的篡改。

## v3.1.0（2026-10-31）— PyQt6 重构版

### 架构
- 客户端与服务端重构为 PyQt6 桌面程序；页面仍由 HTML/JS 实现，通过 QWebEngineView 加载。
- 客户端页面改由本机回环 HTTP 托管，彻底摆脱浏览器对本地文件联网与存储的限制。
- 客户端联机连接改由 Python 持有（QWebSocket），通过 QWebChannel 与页面双向交互；
  同时保留浏览器直连模式，局域网玩家无需安装即可通过服务器页面加入。
- 服务端 HTTP（8080）与 WebSocket（8081）分离：页面/REST 走标准库，权威对局走 QWebSocketServer。
- 协议字段、签名算法与快照结构保持不变，历史成绩仍可校验。

### 客户端
- 新增「灵动岛」：实时显示服务器连接状态与地址，点击即可连接/断开。
- 联机对战入口并入对战模式模块；移除原联机大厅页面。
- 联机排行榜成为独立分类，可按联机单人 / 联机双人查看，仅展示前 30 名。
- 篡改记录自动隐藏上传按钮；新增「一键上传」批量提交正常成绩。
- 支持自制地图上传到服务器，联机建房可直接选用；新增导入/导出与设置页地图管理。
- 修复回放中蛇身颜色与当时皮肤不一致的问题。
- 修复「创建并进入」等按钮因缺少内边距而无高度的问题。
- 设置按功能分组：地图设置 / 外观设置 / 操作设置 / 联机设置 / 数据与统计。
- 操作日志通过 QtSql(SQLite) 持久化，可在设置中导出。
- 支持系统托盘、启动隐藏到托盘与关闭最小化到托盘。

### 服务端
- 主界面改为 Qt 卡片式控制台：运行状态、基本设置、防火墙与自启动、局域网地址、
  房间与连接、联机用户与 IP 备注、实时日志。
- HTML 面板仅保留「访问密码」与「排行榜」，由 QWebEngineView 内嵌显示。
- 访问密码使用 scrypt 高强度哈希 + 会话 Cookie + 失败递增锁定。
- 开机/登录自启动（schtasks），非管理员自动降级为启动文件夹快捷方式；支持一键放行防火墙。
- 支持托盘常驻与 `--tray` 隐藏启动。

### 工程
- 目录重构：`client/`、`server/`、`shared/`、`text/`、`build/`、`release/`、`tests/`、`legacy/`。
- 新增单元/集成测试（签名、引擎、消息流程、HTTP），共 26 项。
- 新增构建与发布工具：`build/sync_version.py`、`build/make_icon.py`、`build/release.py`、
  PyInstaller 规格与一键批处理。
- 全部界面图标为自绘 SVG / QPainter 图形，不使用任何表情符号。
- 旧 Node 版本归档至 `legacy/node-v2/`（不参与构建与发布）。
- 打包产物启动稳定性：默认关闭 Chromium 渲染沙箱（可用同名环境变量覆盖），
  并为窗口态产物补回标准流与崩溃日志 `app.log`（`build/runtime_stdio.py` 运行时钩子）。
- 客户端新增单实例保护：重复启动只唤起已有窗口，避免多实例共享渲染缓存导致白屏。

### 已知限制
- 签名密钥内嵌在客户端：篡改数据后重新计算签名仍可提交；客户端侧的「提交」按钮
  依赖本地校验拦截，服务端只能拦下未重签的篡改。
- 跨公网联机需在路由器上映射 8080/8081/41999 端口。
